# Agent Instructions

All project guidelines, coding standards, and agent rules are maintained in **CLAUDE.md**.

Please read and follow all instructions in [CLAUDE.md](./CLAUDE.md).

## Article Authoring

For any request to start, outline, draft, revise, translate, or publish a blog
article, read and follow the agent-agnostic
[`write-blog-post` skill](./skills/write-blog-post/SKILL.md). It is the
procedural source of truth for article work and loads the shared writing-style
guide.

For any request to finish, finalize, ship, or publish an article, also read and
follow [`finish-blog-post`](./skills/finish-blog-post/SKILL.md). It is the
publication gate for final review, terminology, PT/EN/ES completion, visual QA,
and repository validation.
