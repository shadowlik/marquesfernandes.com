Procurando melhorar a velocidade do seu site WordPress? O uso de um plug-in de cache pode aumentar a velocidade de carregamento, criando uma experiência melhor para seus usuários.

Estatisticamente, quase metade do público-alvo do seu site espera que seu site seja carregado em menos de três segundos. Portanto, não surpreende que o Google continue enfatizando a velocidade do site em seu algoritmo de pesquisa. Quanto maior a velocidade da página, melhores serão os seus rankings de pesquisa e mais tráfego orgânico você poderá atrair.

## O que é Cache?

Simplificando, cache é basicamente uma solução simples para um problema complexo: As páginas no WordPress são geradas dinamicamente, quando um usuário entra em site e acessa, por exemplo, algum artigo, uma requisição pro servidor é feita para que essa página seja processada e entregue, então a linguagem de programação [PHP](http://marquesfernandes.com/o-que-e-php-e-para-que-serve/) entra em ação e realiza diversas consultas no banco de dados para construir a página solicitada e e retorna ela para o usuário.

Conforme a quantidade de acessos em seu site aumentam, isso acaba sobrecarregando o servidor e reduzindo o tempo de resposta da página para o usuário. É ai que o cache entra em ação, como a maioria das páginas não precisam ter o conteúdo necessariamente dinâmico, ele cria um arquivo estático da página, e sempre que o usuário solicitar ele entrega essa página já criada, o que reduz drasticamente o processamento e tempo de resposta. O Cache trabalha normalmente com um tempo de expiração, por exemplo, a sua página inicial pode ter um tempo de expiração de 24hs, quando o Cache espirada, uma nova versão atualizada da página é gerada e servida para os seus usuarios.

Trabalhar com cache no WordPress pode ser complicado, como muitos usuários utilizam temas prontos, a otimização pode se tornar uma tarefa complicada e chata, mas não se preocupe, a maioria dos plug-ins conseguem fazer um excelente trabalho de otimização com pouco esforço.

## Porque Você de usar Cache

-   **Acelera o site para os usuários**: Já cobrimos isso, mas é bom mencionar novamente, pois é a principal vantagem.
-   **Aprimora a experiência geral do usuário**: Como o site carrega mais rapidamente para os usuários, eles agora têm mais probabilidade de navegar, podendo diminuir a taxa de rejeição para o seu site, muitas pessoas não querem esperar 10 segundos para visualizar uma página.
-   **Seu servidor usa menos recursos**: Coloca menos pressão no seu servidor, reduzindo o processamento e memória necessária para aguentar o tranco de muitos usuários, podendo inclusive reduzir custos com hospedagem.
-   **Aumento na otimização de mecanismos de pesquisa**: Você mostra ao Google e a outros buscadores que seu site vale a pena indexar em uma classificação mais alta, pois essa é uma métrica bastante importante para o seu ranqueamento.

### 2\. [WP Super Cache](https://br.wordpress.org/plugins/wp-super-cache/)

[![WP Super Cache](./2020-07-banner-772x250-2.png)](https://br.wordpress.org/plugins/wp-super-cache/)

> Este plugin gera arquivos html estáticos do seu blog dinâmico do WordPress. Depois que um arquivo html é gerado, o seu servidor servirá esse arquivo em vez de processar os scripts PHP do WordPress, que são comparativamente mais pesados e mais custosos.

[WP Super Cache](https://br.wordpress.org/plugins/wp-super-cache/) é um plug-in muito popular de cache para WordPress, com mais de um milhão de instalações ativas. O plugin é mantido pela Automattic, a mesma equipe desenvolvedora do WordPress.com.

O WP Super Cache serve arquivos em cache de três maneiras:

-   **Simples**: Este é o método mais recomendado de armazenamento em cache de arquivos, porque você não precisa editar arquivos PHP, e o arquivo `.htaccess` não precisa ser configurado.
-   **Especialista**: Esse é o método de cache mais rápido e e eficiente porém requer modificação dos arquivos `.htaccess` e configurações adicionais.

### 3\. [W3 Total Cache](https://br.wordpress.org/plugins/w3-total-cache/)

[![W3 Total Cache](./2020-07-banner-772x250-1.jpg)](https://br.wordpress.org/plugins/w3-total-cache/)

> O W3 Total Cache (W3TC) melhora a experiência de SEO e de usuário do seu site, aumentando o desempenho do site e reduzindo os tempos de carregamento, aproveitando recursos como a integração da rede de entrega de conteúdo (CDN) e as práticas recomendadas mais recentes.

[W3 Total Cache](https://www.isitwp.com/wordpress-plugins/w3-cache/) é um dos plugins de cache mais populares do WordPress, com mais de 1 milhão de instalações ativas. Ele melhora o desempenho do servidor, armazenando em cache todos as camadas do site.

Oferece suporte para páginas móveis aceleradas do Google (AMP) e Secure Socket Layer (SSL).

Os desenvolvedores afirmam que o plug-in pode oferecer até 80% de economia de largura de banda através do seu algoritmo de minificação, o processo reduz o tamanho do seu HTML, CSS, JavaScript sem causar um impacto negativo no seu site.

### 4\. [WP Fastest Cache](https://wordpress.org/plugins/wp-fastest-cache/)

[![WP Fastest Cache](./2020-07-banner-772x250-1-1.jpg)](https://wordpress.org/plugins/wp-fastest-cache/)

> O *WP Fastest Cache* - O plugin de cache wordpress mais rápido e fácil.

[WP Fastest Cache](https://wordpress.org/plugins/wp-fastest-cache/) é um dos plugins de cache do WordPress mais fáceis de configurar. Assim como qualquer outro plugin de cache, ele cria arquivos HTML estáticos no seu site dinâmico do WordPress.

Para reduzir o tamanho dos arquivos, o plug-in reduz os arquivos HTML e CSS. Ele efetivamente implementa o cache do navegador para reduzir o tempo de carregamento da página para visitantes repetidos e combina muitos arquivos CSS em um para reduzir o número de requisições feitas para o seu servidor.
