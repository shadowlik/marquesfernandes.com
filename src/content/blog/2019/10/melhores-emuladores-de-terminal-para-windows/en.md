Windows is not known for having the best command line interface, bringing in all its versions the [Command Prompt (CMD)](https://pt.wikipedia.org/wiki/Cmd.exe) , a limited tool, especially compared to UNIX-based terminals. Annoyed developers have created solutions that optimize and even emulate UNIX commands on Microsoft's OS. I've separated a list with some terminals that I've used and recommend.

## [ConEmu](https://conemu.github.io/)

[![ConEmu](http://conemu.github.io/img/ConEmu-Maximus5.png)](https://conemu.github.io/)

[ConEmu](https://conemu.github.io/) is a very complete terminal emulator with support for multiple tabs, windows and a variety of customizations. It has a wide variety of settings and shortcuts. Compatible with almost all popular windows shells like: cmd.exe, [puTTY](https://www.putty.org/) , [PowerShell](https://docs.microsoft.com/en-us/powershell/scripting/overview?view=powershell-6) , [Git Bash](https://git-scm.com/downloads) and [others](https://conemu.github.io/en/TableOfContents.html#bash-on-windows) ...

One of the many features that really appeals to me is the " **Always on Top** " which allows the window to always be in the foreground.

## [cmder](https://cmder.net/)

[![cmder](https://cmder.net/img/main.png)](https://cmder.net/)

> Cmder is software created out of sheer frustration over the lack of console emulators in Windows. Based on amazing software (ConEmu), and spiced up with the Monokai color scheme and custom layout, visibly sexy right from the start.
> 
> [cmder](https://cmder.net/)

[commander](https://cmder.net/) is basically an extension of the [ConEmu](https://conemu.github.io/) , with some configuration improvements and customizations.

## [MobaXterm](https://mobaxterm.mobatek.net/)

[![MobaXterm](https://mobaxterm.mobatek.net/img/slider/MobaXterm.png)](https://mobaxterm.mobatek.net/)

[MobaXterm](https://mobaxterm.mobatek.net/) is an extremely complete program that allows you to easily manage remote access tools like SSH, VNC, FTP,... It also has unix commands like bash, ls, cat, sed, grep, ...

Called " **All-In-One network application** ", is an excellent program to organize and perform daily tasks such as accessing remote servers with SSH and even allows shell integration with a graphical FTP interface.

## [(New) Windows Terminal](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

[![Windows Terminal (Preview)](http://devblogs.microsoft.com/commandline/wp-content/uploads/sites/33/2019/08/terminal0.4.png)](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

Knowing about this problem, Microsoft announced that it is working on a new terminal with more features:

-   multiple tabs
-   Linux command support through [Windows Subsystem for Linux](https://tecnoblog.net/237551/microsoft-windows-10-linux-distribuicoes/)
-   Themes and Customization
-   GPU-based full text rendering and even emoji

One [beta version](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab) is already available on [Microsoft Store](https://www.microsoft.com/pt-br/store/b/home) .
