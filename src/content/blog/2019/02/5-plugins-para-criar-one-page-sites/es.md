Los sitios de una sola página (One Page) se están usando mucho para proyectos que tienen contenido reducido y una estructura sencilla, convirtiéndose en una gran alternativa para presentar información de manera simple y objetiva. Existen varios plugins de código abierto que pueden ayudarte en esta tarea; ofrecen muchos recursos como animación y funcionalidades para menús fijos y presentaciones.

### [Fullpage.js](http://alvarotrigo.com/fullPage/)

FullPage.js es un plugin simple y fácil de usar para crear sitios de desplazamiento horizontal y vertical. Diseñado para soportar diseños responsivos, eso lo convierte en mi favorito de la lista. [![full page javascript](https://cloud.marquesfernandes.com/images/full-page-javascript.jpg)](http://alvarotrigo.com/fullPage/)  

### [One Page Scroll](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)

Perfecto para crear sitios de presentación. [![onepage scroll](https://cloud.marquesfernandes.com/images/onepage-scroll.jpg)](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)  

### [Smint](http://www.outyear.co.uk/smint/)

Plugin simple que facilita la navegación en sitios one page. [![smint3](https://cloud.marquesfernandes.com/images/smint3.jpg)](http://www.outyear.co.uk/smint/)  

### [Stickup](http://lirancohen.github.io/stickUp/)

Plugin simple que fija la barra de navegación cuando el scroll pasa por ella. [![stickup2](https://cloud.marquesfernandes.com/images/stickup2.jpg)](http://lirancohen.github.io/stickUp/)  

### [jQuery Scroll Path](http://joelb.me/scrollpath/)

Un plugin loco que te permite hacer tu propia ruta de scroll; si alguien consigue hacer un diseño genial con este plugin, ¡por favor mándame el caso! [![jQuery Scroll Path1](https://cloud.marquesfernandes.com/images/jQuery-Scroll-Path1.jpg)](http://joelb.me/scrollpath/)

### Recomendación

[One Page Love](http://onepagelove.com/) es un sitio muy bueno para quien busca ideas y referencias para el diseño de sitios al estilo one page. Además de una inmensa colección de sitios, tiene una sección para la compra de plantillas en la misma línea de diseño.
