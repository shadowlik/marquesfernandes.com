Looking for examples of REST documentation online? I separated 5 APIs documentation that recently helped me as inspiration.

[Twitter API](https://dev.twitter.com/overview/api)

![](/wp-content/uploads/2019/09/07160155479276-1024x384.jpg)

Twitter (English:\[ˈtwɪtər\] ) is a social network and server for microblogging, which allows users to send and receive personal updates from other contacts (in texts of up to 280 characters, known as "tweets"), via the service's website, via SMS and via software management specifics.

[Github API](https://developer.github.com/v3/#parameters)

![](/wp-content/uploads/2019/09/what-is-github-1-1-1024x512.png)

GitHub is a source code hosting platform with version control using Git.

[Google Drive API](https://developers.google.com/drive/v2/reference/files#resource)

![](/wp-content/uploads/2019/09/Google-Drive-Apps-Main.png)

Google Drive is a file storage and sync service that was introduced by Google on April 24, 2012.

[Paypal API](https://developer.paypal.com/docs/api/overview/)

![](/wp-content/uploads/2019/09/wpca-paypal-gateway-addon-815x458.jpg)

PayPal is an online payment company based in San Jose, California, United States. Founded in 1998 by Peter Thiel and Max Levchin, it operates internationally and is one of the largest in the business as it is able to make quick payments and assist with money transfers.

[VTEX Catalog API](https://documenter.getpostman.com/view/845/vtex-catalog-api/Hs44?version=latest)

![](/wp-content/uploads/2019/09/vtex-1-1024x576.jpg)

VTEX is a Brazilian technology multinational focused on cloud commerce, developer of the VTEX Cloud commerce platform, available on the market as SaaS with global operations.
