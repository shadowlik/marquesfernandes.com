No se sabe que Windows tenga la mejor interfaz de línea de comandos, trayendo en todas sus versiones el [símbolo del sistema (CMD)](https://pt.wikipedia.org/wiki/Cmd.exe), una herramienta limitada, especialmente cuando se compara con terminales basados en UNIX. Los desarrolladores problemáticos han creado soluciones que optimizan e incluso emulan comandos UNIX en el sistema operativo Microsoft. He separado una lista con algunos terminales que he utilizado y recomiendo.

## [Conemu, Año Nuevo](https://conemu.github.io/)

[![Conemu, Año Nuevo](http://conemu.github.io/img/ConEmu-Maximus5.png)](https://conemu.github.io/)

[ConEmu](https://conemu.github.io/) es un emulador de terminal bien completo con soporte para múltiples pestañas, ventanas y una variedad de personalizaciones. Tiene una amplia variedad de ajustes y accesos directos. Compatible con casi todas las cáscaras de Windows populares como: cmd.exe, [PuTTY](https://www.putty.org/), [PowerShell](https://docs.microsoft.com/en-us/powershell/scripting/overview?view=powershell-6), [Git Bash](https://git-scm.com/downloads) y [otros](https://conemu.github.io/en/TableOfContents.html#bash-on-windows)...

Una de las muchas características que me atrae mucho es el "Siemp**re en la parte** superior" que permite que la ventana esté siempre en primer plano.

## [cmder, Nuevo](https://cmder.net/)

[![cmder, Nuevo](https://cmder.net/img/main.png)](https://cmder.net/)

> Cmder es un software creado a partir de la pura frustración por la falta de emuladores de consola en Windows. Basado en un software increíble (ConEmu), y picante con el esquema de color Monokai y un diseño personalizado, visiblemente sexy desde el principio.
> 
> \-ERR:REF-NOT-FOUND-[cmder, Nuevo](https://cmder.net/)

[Cmder](https://cmder.net/) es básicamente una extensión de [ConEmu](https://conemu.github.io/), con algunas mejoras de configuración y personalizaciones.

## [MobaXterm](https://mobaxterm.mobatek.net/)

[![MobaXterm](https://mobaxterm.mobatek.net/img/slider/MobaXterm.png)](https://mobaxterm.mobatek.net/)

[MobaXterm](https://mobaxterm.mobatek.net/) es un programa extremadamente completo que le permite gestionar fácilmente herramientas de acceso remoto como SSH, VNC, FTP, ... También tiene comandos unix como bash, ls, cat, sed, grep, ...

Llamada la **"aplicación de red todo en uno**", es un excelente programa para organizar y realizar tareas diarias como el acceso a servidores remotos con SSH e incluso permite la integración del shell con una interfaz FTP gráfica.

## [(Nuevo) Windows Terminal](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

[![Terminal de Windows (versión preliminar)](http://devblogs.microsoft.com/commandline/wp-content/uploads/sites/33/2019/08/terminal0.4.png)](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

Sabiendo este problema Microsoft anunció que está trabajando en un nuevo terminal con más funcionalidad:

-   Múltiples pestañas
-   Soporte para el comando linux a través del [subsistema de Windows para Linux](https://tecnoblog.net/237551/microsoft-windows-10-linux-distribuicoes/)
-   Temas y personalización
-   Representación de texto completo basada en GPU e incluso emoji

Una [versión beta](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab) ya está disponible en [Microsoft Store](https://www.microsoft.com/pt-br/store/b/home).
