Windows não é conhecido por ter a melhor interface para linha de comando, trazendo em todas as suas versões o [Prompt de Comando (CMD)](https://pt.wikipedia.org/wiki/Cmd.exe), uma ferramenta limitada, principalmente se comparada com terminais baseados em UNIX. Desenvolvedores incomodados criaram soluções que otimizam e inclusive emulam comandos UNIX no SO da Microsoft. Separei uma lista com alguns terminais que já usei e recomendo.

## [ConEmu](https://conemu.github.io/)

[![ConEmu](http://conemu.github.io/img/ConEmu-Maximus5.png)](https://conemu.github.io/)

[ConEmu](https://conemu.github.io/) é um emulador de terminal bem completo com suporte para múltiplas abas, janelas e uma variedade de customizações. Conta com uma ampla variedade de ajustes e atalhos. Compatível com quase todas as shells populares de windows como: cmd.exe, [PuTTY](https://www.putty.org/), [PowerShell](https://docs.microsoft.com/en-us/powershell/scripting/overview?view=powershell-6), [Git Bash](https://git-scm.com/downloads) e [outros](https://conemu.github.io/en/TableOfContents.html#bash-on-windows)...

Uma das muitas funcionalidades que me atrai bastante é o "**Always on Top**" que permite que a janela fique sempre em primeiro plano.

## [cmder](https://cmder.net/)

[![cmder](https://cmder.net/img/main.png)](https://cmder.net/)

> Cmder é um software criado a partir de pura frustração sobre a falta de emuladores de console no Windows. Baseado em um software incrível (ConEmu), e apimentado com o esquema de cores Monokai e um layout customizado, visivelmente sexy desde o começo.
> 
> [cmder](https://cmder.net/)

[Cmder](https://cmder.net/) é basicamente uma extensão do [ConEmu](https://conemu.github.io/), com algumas melhorias de configurações e customizações.

## [MobaXterm](https://mobaxterm.mobatek.net/)

[![MobaXterm](https://mobaxterm.mobatek.net/img/slider/MobaXterm.png)](https://mobaxterm.mobatek.net/)

[MobaXterm](https://mobaxterm.mobatek.net/) é um programa extremamente completo que permite facilmente gerenciar ferramentas de acesso remoto como SSH, VNC, FTP, ... Conta também com comandos unix como bash, ls, cat, sed, grep, ...

Chamado de "**All-In-One network application**", é um programa excelente para organizar e executar tarefas diarias como acesso a servidores remotos com SSH e inclusive permite a integração do shell com uma interface gráfica de FTP.

## [(Novo) Windows Terminal](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

[![Windows Terminal (Preview)](http://devblogs.microsoft.com/commandline/wp-content/uploads/sites/33/2019/08/terminal0.4.png)](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab)

Sabendo desse problema a Microsoft anunciou que está trabalhando em um novo terminal com mais funcionalidades:

-   Múltiplas abas
-   Suporte para comando linux através do [Subsistema do Windows para Linux](https://tecnoblog.net/237551/microsoft-windows-10-linux-distribuicoes/)
-   Temas e Personalização
-   Renderização de texto completa baseada em GPU e até mesmo emoji

Uma [versão beta](https://www.microsoft.com/en-us/p/windows-terminal-preview/9n0dx20hk701?activetab=pivot:overviewtab) já está disponível na [Microsoft Store](https://www.microsoft.com/pt-br/store/b/home).
