More and more the creation of amateur IoT (Internet of Things) projects is becoming viable, cheaper boards and parts allowing the wide access and development of community projects. I separated a list with some projects to inspire your projects in 2020! The project tutorials are in English, but nothing that the Google translation doesn't count...

## 1\. Door Lock with Face Recognition - Raspberry PI

![1\. Door Lock with Face Recognition - Raspberry PI](https://hackster.imgix.net/uploads/cover_image/file/113243/facialrecognitiondoor-snapshot.JPG?auto=compress&w=900&h=675&fit=min&fm=jpg)

Using a Raspberry Pi, a camera and a solenoid lock to create a lock that unlocks when it recognizes your face!

[Check out the project](https://maker.pro/raspberry-pi/projects/how-to-create-a-facial-recognition-door-lock-with-raspberry-pi)

## two. Temperature and Humidity Monitor - Arduino

![two. Temperature and Humidity Monitor - Arduino](https://www.electronicsforu.com/wp-contents/uploads/2017/02/672.jpg)

A basic project to monitor the temperature and humidity of environments!

[Check out the project](https://www.electronicsforu.com/electronics-projects/humidity-temperature-monitoring-using-arduino-esp8266)

## 3\. Smart Irrigation System for Your Garden - **Arduino**

![3\. Intelligent Irrigation System for your Garden - Arduino](https://www.ubuntupit.com/wp-content/uploads/2019/07/iot-based-water-irrigation-system.jpg)

This IoT project proposes an automated irrigation system that can analyze soil moisture and weather conditions. Users will be able to check the moisture level and, with the preset threshold for a soil moisture level, the power supply will be cut off.

[Check out the project](https://www.electronicsforu.com/electronics-projects/humidity-temperature-monitoring-using-arduino-esp8266)

## 4\. Recycle Bin Level Monitoring - Arduino

![4\. Recycle Bin Level Monitoring - Arduino](/wp-content/uploads/2020/03/image-13-1024x543.jpg)

This IoT project uses an ultrasonic sensor to detect the level of trash in each dump and send that data to the main program. A page in the browser shows the trash level in each trash bin.

[Check out the project](https://nevonprojects.com/iot-garbage-monitoring-system/)

## 5\. Real Time Tracker - Arduino

![5\. Real Time Tracker - Arduino](https://hackster.imgix.net/uploads/attachments/401127/road_test_data_1_tjcsN4SMWa.PNG?auto=compress%2Cformat&w=680&h=510&fit=max)

How about creating a GPS tracker using an Arduino and viewing the data on two free IoT dashboards?

[Check out the project](https://create.arduino.cc/projecthub/botletics/real-time-2g-3g-lte-arduino-gps-tracker-iot-dashboard-01d471?ref=tag&ref_id=tracking&offset=2)
