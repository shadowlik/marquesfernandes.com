**ASCII** , from English *American Standard Code for Information* (American Standard Code for Information Exchange). It is a 7-bit character code, where each bit represents a single character. Here you will find the 8-bit ASCII table, 256 characters, according to the [Windows-1252](https://en.wikipedia.org/wiki/Windows-1252) , which is a superset of the [ISO 8859-1](https://www.iso.org/standard/28245.html) in terms of printable characters. In the range 128 to 159 (hex 80 to 9F), ISO / IEC 8859-1 has invisible control characters, while Windows-1252 has writable characters. THE **Windows-1252** it is probably the most used 8-bit character encoding in the world.

***See too:** [Complete Base64 Character Table - Encoding/Decoding](http://marquesfernandes.com/tabela-de-caracteres-base64-completa-codificacao-decodificacao/)*

## ASCII control characters (character code 0-31)

The first 32 characters in the ASCII table are "non-printable" control codes and are used primarily for controlling peripherals such as printers.
