Cada vez más la creación de proyectos amateurs de IoT (Internet de las Cosas) se ha vuelto viable, placas y piezas más baratas que permiten el amplio acceso y desarrollo de proyectos comunitarios. ¡Separé una lista con algunos proyectos para inspirar tus proyectos en 2020! Los tutoriales de los proyectos están en inglés, pero nada que la traducción de Google no tiene en cuenta ...

## 1\. Bloqueo de puerta con reconocimiento facial - Raspberry PI

![1\. Bloqueo de puerta con reconocimiento facial - Raspberry PI](https://hackster.imgix.net/uploads/cover_image/file/113243/facialrecognitiondoor-snapshot.JPG?auto=compress&w=900&h=675&fit=min&fm=jpg)

Usando una Raspberry Pi, una cámara y un cansánideo para crear un candado que se desbloquea cuando reconoce su cara!

[Echa un vistazo al proyecto](https://maker.pro/raspberry-pi/projects/how-to-create-a-facial-recognition-door-lock-with-raspberry-pi)

## 3\. Sistema de riego inteligente para su jardín - **Arduino**

![3\. Sistema de riego inteligente para su jardín - Arduino](https://www.ubuntupit.com/wp-content/uploads/2019/07/iot-based-water-irrigation-system.jpg)

Este proyecto de IoT propone un sistema de riego automatizado que puede analizar la humedad del suelo y las condiciones climáticas. Los usuarios podrán comprobar el nivel de humedad y, con el límite preestablecido para un nivel de humedad del suelo, se cortará la fuente de alimentación.

## 4\. Monitoreo de nivel de basura - Arduino

![4\. Monitoreo de nivel de basura - Arduino](./2020-03-image-13.jpg)

Este proyecto de IoT utiliza un sensor ultrasónico para detectar el nivel de basura en cada papelera de reciclaje y enviar estos datos al programa principal. Una página del explorador muestra el nivel de elementos no utilizados en cada papelera de reciclaje.

[Echa un vistazo al proyecto](https://nevonprojects.com/iot-garbage-monitoring-system/)
