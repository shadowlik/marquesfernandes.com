Sites de uma única página (One Page) estão sendo muito usados para projetos que possuem conteúdo enxuto e estrutura reduzida, virando uma ótima alternativa para apresentar informações de maneira simples e objetiva. Existem vários plugins open source que podem ajuda-lo nessa empreitada, eles oferecem muitos recursos como animação e funcionalidades para menus fixos e apresentações.

### [Fullpage.js](http://alvarotrigo.com/fullPage/)

FullPage.js é um plugin simples e fácil de usar para criar sites de rolagem horizontais e verticais. Projetado para suportar designs responsivos faz dele o meu favorito da lista. [![full page javascript](https://cloud.marquesfernandes.com/images/full-page-javascript.jpg)](http://alvarotrigo.com/fullPage/)  

### [One Page Scroll](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)

Perfeito para criar sites de apresentação. [![onepage scroll](https://cloud.marquesfernandes.com/images/onepage-scroll.jpg)](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)  

### [Smint](http://www.outyear.co.uk/smint/)

Plugin simples que facilita na navegação de sistes one page. [![smint3](https://cloud.marquesfernandes.com/images/smint3.jpg)](http://www.outyear.co.uk/smint/)  

### [Stickup](http://lirancohen.github.io/stickUp/)

Plugin simples que cola a barra de navegação quando o scroll passar por ela. [![stickup2](https://cloud.marquesfernandes.com/images/stickup2.jpg)](http://lirancohen.github.io/stickUp/)  

### [jQuery Scroll Path](http://joelb.me/scrollpath/)

Um plugin maluco que permite que você faça sua própria rota de scroll, se alguém conseguir fazer um design legal com esse plugin por favor me manda o case! [![jQuery Scroll Path1](https://cloud.marquesfernandes.com/images/jQuery-Scroll-Path1.jpg)](http://joelb.me/scrollpath/)

### Recomendação

[One Page Love](http://onepagelove.com/)  é um site muito bom para quem busca ideias e referências para design de sites no estilo one page. Além de uma coletânea imensa de sites possui uma sessão para compra de templates na mesma linha de design.
