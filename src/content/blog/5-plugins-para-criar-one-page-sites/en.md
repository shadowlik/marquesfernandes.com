Single-page (One Page) sites are being widely used for projects that have lean content and a reduced structure, becoming a great alternative to present information in a simple and objective way. There are several open source plugins that can help you in this endeavor; they offer many features such as animation and functionality for fixed menus and presentations.

### [Fullpage.js](http://alvarotrigo.com/fullPage/)

FullPage.js is a simple and easy-to-use plugin to create horizontal and vertical scrolling sites. Designed to support responsive designs, it makes it my favorite on the list. [![full page javascript](https://cloud.marquesfernandes.com/images/full-page-javascript.jpg)](http://alvarotrigo.com/fullPage/)  

### [One Page Scroll](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)

Perfect for creating presentation sites. [![onepage scroll](https://cloud.marquesfernandes.com/images/onepage-scroll.jpg)](http://www.thepetedesign.com/demos/onepage_scroll_demo.html)  

### [Smint](http://www.outyear.co.uk/smint/)

A simple plugin that makes navigation easier on one page sites. [![smint3](https://cloud.marquesfernandes.com/images/smint3.jpg)](http://www.outyear.co.uk/smint/)  

### [Stickup](http://lirancohen.github.io/stickUp/)

A simple plugin that sticks the navigation bar when the scroll passes by it. [![stickup2](https://cloud.marquesfernandes.com/images/stickup2.jpg)](http://lirancohen.github.io/stickUp/)  

### [jQuery Scroll Path](http://joelb.me/scrollpath/)

A crazy plugin that lets you make your own scroll path; if anyone manages to make a cool design with this plugin please send me the case! [![jQuery Scroll Path1](https://cloud.marquesfernandes.com/images/jQuery-Scroll-Path1.jpg)](http://joelb.me/scrollpath/)

### Recommendation

[One Page Love](http://onepagelove.com/) is a very good site for those looking for ideas and references for one page style site design. In addition to a huge collection of sites, it has a section to buy templates in the same design line.
