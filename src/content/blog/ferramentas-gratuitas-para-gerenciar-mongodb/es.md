Hay varias herramientas disponibles en el mercado para administrar su base de datos [MongoDB](https://www.mongodb.com/). Han mejorado la productividad en el desarrollo, la administración y también ayudan a reducir la curva de aprendizaje para aquellos que comienzan con la base de datos [nosql](https://pt.wikipedia.org/wiki/NoSQL) o que provienen de [SQL](https://dicasdeprogramacao.com.br/o-que-e-sql/). He separado una lista con algunas de las herramientas más populares y gratuitas que he utilizado y recomiendo.

## [Robo 3T (anteriormente Robomongo)](https://robomongo.org/)

[![Robo 3T (anteriormente Robomongo)](https://robomongo.org/static/screens-transparent-6e2a44fd.png)](https://robomongo.org/)

Robo 3T (anteriormente Robomongo) es una de las interfaces gráficas más populares y gratuita para los amantes de MongoDB. Ligero y de código abierto, es compatible con múltiples plataformas (Mac, Linux y Windows) y también incorpora la línea de comandos [mongo](https://docs.mongodb.com/manual/mongo/) en la aplicación para proporcionar interacción a usuarios más avanzados. Está desarrollado por 3T Software, el equipo detrás de IDE [Studio 3T](https://studio3t.com/).

### Características clave

-   Línea de comandos integrada
-   Interfaz asincrónica y sin bloqueos
-   Soporte para MongoDB 4.0+

## [NoSQLBooster (anteriormente MongoBooster)](https://nosqlbooster.com/)

![NoSQLBooster (anteriormente MongoBooster)](https://nosqlbooster.com/s3/img/home-intellisense-v5.gif)

NoSQLBooster (anteriormente MongoBooster) es otra herramienta popular para administrar su base de datos. Disponible en varias plataformas (Mac, Linux y Windows) está centrado en mongo y proporciona capacidades de supervisión, generador de consultas de autocompletar, consultas SQL y compatibilidad con sintaxis ES2017.

### Características clave

-   Autocompletado inteligente
-   Consultas SQL
-   Construcción de consultas encadenadas
-   Análisis de esquemas
-   Supervisión del servidor

## [NoSQL Manager](https://www.mongodbmanager.com/)

[![NoSQL Manager](https://res.cloudinary.com/practicaldev/image/fetch/s--KAMfdhxz--/c_limit%2Cf_auto%2Cfl_progressive%2Cq_auto%2Cw_880/https://scalegrid.io/blog/wp-content/uploads/2016/09/2019-Best-MongoDB-GUI-NoSQL-Manager-Favorite-Scripts.png)](https://www.mongodbmanager.com/)

Esta herramienta de administración combina la interfaz fácil de usar y la potencia de la línea de comandos. Ofrece un alto rendimiento con soporte para todas las últimas características de MongoDB y MongoDB Enterprise.

### Características clave

-   Interfaz gráfica para la línea de comandos de MongoDB con autocompletar código
-   Tres vistas: árbol, tabla y JSON.
-   Importar tablas desde bases de datos MySQL y SQL Server
-   Exportar documentos a formatos CSV, XML, XLSX y JSON

## [Brújula MongoDB](https://www.mongodb.com/products/compass)

![Brújula MongoDB](https://webassets.mongodb.com/_com_assets/cms/image05-89d200e38f.png)

MongoDB Compass es desarrollado por el propio equipo de MongoDB. Proporciona a los usuarios una vista gráfica de su esquema MongoDB sin necesidad de lenguaje de consulta de línea de comandos.

### Características clave

-   MongoDB Compass analiza documentos y muestra estructuras clave en una colección mediante consultas ad hoc en segundos
-   Admite información rápida sobre el estado del servidor y el rendimiento de las consultas
-   Le permite ver el rendimiento de las consultas
-   Ayuda a los usuarios a tomar decisiones sobre indexación, validación de documentos y más
-   No es necesario escribir en la línea de comandos
