Você tem um site mas sente que ele não oferece benefícios na condução de seus negócios? Selecionamos **4 fatores** que podem estar **afetando** o desempenho das suas páginas. Identificá-los e corrigi-los podem trazer resultados a curto prazo.

## 1\. Não há uso consistente de palavras-chave

![pesquisa de palavras chaves](./2015-09-images_pesquisa_de_palavras_chaves_1.png) Atualmente, utilizamos o Google para pesquisar qualquer tipo de informação. Quando realizamos uma busca, a ferramenta **correlaciona** as palavras buscadas com partes importantes da estrutura de um site e exibe um ranking por ordem de relevância com o objetivo de apresentar resultados satisfatórios para o usuário. Para as empresas, assumir as **primeiras posições** de pesquisas significa obter maior audiência e vantagem competitiva. Existem muitos aspectos do site que dão dicas para o Google sobre o conteúdo de uma página como palavras-chaves, títulos e endereços. Para **aumentar** a possibilidade de obter uma **boa posição** no ranking para palavras relacionadas ao seu negócio, realizar uma pesquisa para identificar o que e como as pessoas procuram sobre determinado tema é fundamental para colher bons resultados. Para isso, é preciso analisar a **quantidade de buscas** e a **concorrência** por cada **palavras-chave**. Vale ressaltar que palavras com grande volume de buscas tendem a ter maior disputa pelas primeiras posições e dificilmente será possível competir com sites que já estão sendo bem avaliados pelo Google.

## 2\. Seu site não é adaptado para dispositivos móveis

![design responsivo](./2015-09-images_design_responsivo.png) Toda companhia precisa conduzir seus negócios com base nas **tendências** e na constante **evolução** da internet em vez de continuar apostando em antigos formatos. Com o crescimento agressivo do uso de smartphones, hoje, ter um site adaptado para dispositivos móveis já não é mais opção, mas sim, uma **obrigação** para quem não quer ficar para trás. Segundo estudo, **48%** dos usuários dizem que se um site de negócios não está funcionando bem no celular, eles tomam isso com uma indicação de que a companhia simplesmente **não está se importando** com o consumidor. Além de oferecer melhor experiência para o usuário, ter um site adaptado para qualquer tipo de tela se tornou critério de **grande peso** para a colocação nos buscadores como determinado pelo Google no dia 21 de abril de 2015.

## 3\. Seu site é lento em todos os dispositivos

![site lento](./2015-09-images_site_lento.png) O **tempo de carregamento** é outro ponto importante que torna um site mais **acessível** e **útil** para os usuários. Segundo estatística, **40%** das pessoas **abandonarão** uma página da web se ela **demorar** mais que **três segundos para carregar**. A configuração do servidor, estrutura HTML de uma página e seu uso de recursos externos, tais como imagens, JavaScript e CSS são alguns aspectos que afetam a velocidade das páginas. Formate corretamente imagens para economizar bytes de dados, reduza o tempo de resposta do servidor, defina uma data de validade ou de uma idade máxima nos cabeçalhos de HTTP para aproveitar o cache do navegador são algumas recomendações do Google para **melhorar a velocidade**.

## 4\. O Layout é obsoleto e poluído

![layout obsoleto](./2015-09-images_layout_obsoleto.png) Além de afetar o tempo de carregamento, **layouts antigos** tendem a expressar **falta de credibilidade** e podem fazer com que os usuários simplesmente abandonem seu site sem interagir com nenhuma informação. Em um estudo sobre os fatores que faziam usuários **confiar** ou **desconfiar** de um site, **94 de cada 100 respostas** diziam que era devido ao **design**. Interfaces visualmente bonitas, intuitivas, mais limpas e leves podem contribuir para: - Aumentar o tempo de permanência no site; - Diminuir a taxa de rejeição; - Elevar o tráfego no site; - Aumentar as conversões e vendas, no caso de e-commerce. É importante contratar uma **empresa especializada** para corrigir esses elementos. A internet está em constante melhoria.
